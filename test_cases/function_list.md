# 테스트 케이스 기능 목록

**프로젝트:** Y2O3 Focus Ring 마모도 예측 및 공정 로그 상관관계 분석  
**작성일:** 2024-12-19  
**목적:** 테스트 케이스 작성을 위한 기능 목록 정의

---

## 📋 기능 목록 개요

이 문서는 Y2O3 Focus Ring 예지보전 시스템의 모든 기능을 체계적으로 정리한 목록입니다. 각 기능은 테스트 케이스 작성의 기초가 됩니다.

## 1. 데이터 수집 및 전처리 기능

### 1.1 RF 파라미터 데이터 수집
- **F-001**: Vpp (Peak-to-Peak Voltage) 데이터 수집
- **F-002**: Vdc (Self-Bias Voltage) 데이터 수집
- **F-003**: Phase Angle (RF 매칭 위상) 데이터 수집
- **F-004**: Matcher Position 데이터 수집
- **F-005**: RF 파라미터 실시간 스트리밍 수집
- **F-006**: RF 파라미터 배치 데이터 수집
- **F-007**: RF 파라미터 데이터 검증 (범위 체크)
- **F-008**: RF 파라미터 결측값 처리

### 1.2 OES 데이터 수집
- **F-009**: OES Yttrium Peak 데이터 수집
- **F-010**: F/O/Ar Intensity Ratio 데이터 수집
- **F-011**: OES 데이터 실시간 수집
- **F-012**: OES 데이터 검증 (범위 체크)
- **F-013**: OES 데이터 결측값 처리

### 1.3 환경/계측 데이터 수집
- **F-014**: 누적 RF On-Time 데이터 수집
- **F-015**: 누적 에너지 (Joule) 계산 및 수집
- **F-016**: Recipe Severity 데이터 수집
- **F-017**: PM 계측 데이터 (두께 측정값) 수집
- **F-018**: 소모품 중량 변화 데이터 수집
- **F-019**: 교체 이력 데이터 수집

### 1.4 데이터 전처리
- **F-020**: 결측값 보간 (선형 보간)
- **F-021**: 이상치 탐지 및 처리
- **F-022**: 데이터 정규화/표준화
- **F-023**: 챔버별 센서 보정 적용
- **F-024**: 시간 동기화 (RF 파라미터와 OES 데이터)
- **F-025**: 데이터 품질 검증

## 📝 테스트 케이스 작성 가이드

각 기능에 대해 다음 항목을 포함한 테스트 케이스를 작성합니다:

1. **테스트 ID**: 기능 ID 기반 (예: TC-F-001)
2. **테스트 목적**: 테스트의 목적 명시
3. **전제 조건**: 테스트 실행 전 필요한 조건
4. **테스트 단계**: 단계별 테스트 절차
5. **예상 결과**: 각 단계별 예상 결과
6. **실제 결과**: 실제 테스트 결과 (테스트 실행 시 작성)
7. **테스트 상태**: [통과 / 실패 / 차단]
8. **비고**: 추가 사항
