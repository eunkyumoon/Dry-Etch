# Reports 폴더

이 폴더는 Dry Etch 소모품(Y2O3 Ring) 예지보전 프로젝트의 다양한 리포트 템플릿을 포함합니다.

## 📁 파일 목록

### 1. `project_progress_template.md`
프로젝트 진행 상황을 정기적으로 보고하기 위한 템플릿입니다.
- 프로젝트 현황 요약
- 세부 진행 상황
- 성공 지표 달성 현황
- 비용 절감 현황
- 리스크 및 이슈
- 다음 단계 계획

### 2. `cost_savings_report_template.md`
비용 절감 실적을 분석하고 보고하기 위한 템플릿입니다.
- 소모품 구매 비용 절감 분석
- 장비 다운타임 비용 절감 분석
- 품질 불량 비용 절감 분석
- 누적 효과 분석
- 목표 대비 달성률

### 3. `model_performance_report_template.md`
모델 성능을 평가하고 보고하기 위한 템플릿입니다.
- 모델 개요 및 아키텍처
- RUL 예측 정확도 평가
- 마모 진행도 추정 정확도 평가
- 이상 탐지 성능 평가
- 특성 중요도 분석
- 오류 분석 및 개선 제안

### 4. `monthly_report_template.md`
월간 운영 현황을 보고하기 위한 템플릿입니다.
- 월간 요약
- 상세 활동 내역
- 성과 지표
- 비용 절감 현황
- 이슈 및 대응
- 다음 달 계획

## 📝 사용 방법

1. 원하는 리포트 템플릿 파일을 복사합니다.
2. 파일명을 적절히 변경합니다 (예: `project_progress_2024_12.md`).
3. 템플릿의 `{변수명}` 부분을 실제 데이터로 채웁니다.
4. 필요에 따라 섹션을 추가하거나 수정합니다.

## 📊 리포트 작성 가이드라인

- **명확성**: 기술 용어를 사용하되 이해하기 쉽게 설명
- **구조화**: 일관된 구조와 형식 유지
- **데이터 기반**: 모든 주장은 데이터로 뒷받침
- **시각화**: 복잡한 데이터는 차트/그래프로 표현
- **액션 아이템**: 구체적인 다음 단계 제시

## 🔄 리포트 주기

- **프로젝트 진행 리포트**: 주간 또는 월간
- **비용 절감 리포트**: 월간 또는 분기별
- **모델 성능 평가 리포트**: 모델 업데이트 시 또는 분기별
- **월간 리포트**: 매월 말
