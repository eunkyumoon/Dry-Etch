# Prompting 폴더

이 폴더는 Dry Etch 소모품(Y2O3 Ring) 예지보전 프로젝트에서 사용할 AI 프롬프트 템플릿을 포함합니다.

## 📁 파일 목록

### 1. `data_analysis_prompting.md`
데이터 분석을 위한 프롬프트 템플릿입니다.
- 기본 데이터 분석 프롬프트
- 시계열 데이터 분석 프롬프트
- 챔버별 비교 분석 프롬프트
- 레시피 영향도 분석 프롬프트

**사용 시나리오:**
- 실시간 마모 상태 평가
- 시계열 데이터 추세 분석
- 챔버별 성능 비교
- 레시피별 마모 영향도 분석

### 2. `model_training_prompting.md`
모델 학습을 위한 프롬프트 템플릿입니다.
- 모델 학습 가이드 프롬프트
- 데이터 전처리 프롬프트
- 특성 엔지니어링 프롬프트
- 모델 아키텍처 설계 프롬프트
- 하이퍼파라미터 튜닝 프롬프트
- 전이 학습 프롬프트
- 모델 평가 프롬프트

**사용 시나리오:**
- 모델 개발 초기 단계
- 데이터 전처리 작업
- 모델 아키텍처 설계
- 하이퍼파라미터 최적화
- 신규 레시피 대응 (전이 학습)

### 3. `report_generation_prompting.md`
리포트 자동 생성을 위한 프롬프트 템플릿입니다.
- 프로젝트 진행 리포트 생성 프롬프트
- 비용 절감 리포트 생성 프롬프트
- 모델 성능 평가 리포트 생성 프롬프트
- 월간 리포트 생성 프롬프트
- 알람 리포트 생성 프롬프트
- 데이터 품질 리포트 생성 프롬프트

**사용 시나리오:**
- 정기 리포트 자동 생성
- 데이터 기반 리포트 작성
- 다양한 리포트 형식 생성

### 4. `anomaly_detection_prompting.md`
이상 탐지를 위한 프롬프트 템플릿입니다.
- 실시간 이상 탐지 프롬프트
- Arcing 위험 탐지 프롬프트
- 급격한 마모 탐지 프롬프트
- 센서 이상 탐지 프롬프트
- 패턴 이상 탐지 프롬프트
- 종합 이상 분석 프롬프트

**사용 시나리오:**
- 실시간 모니터링 시스템
- 이상 징후 조기 경보
- Arcing 위험 예측
- 센서 데이터 검증

## 📝 사용 방법

### 기본 사용법
1. 원하는 프롬프트 템플릿 파일을 엽니다.
2. 해당 프롬프트를 복사합니다.
3. `{변수명}` 부분을 실제 값으로 대체합니다.
4. AI 모델 (ChatGPT, Claude 등)에 입력합니다.

### 예시
```python
# 프롬프트 템플릿 읽기
with open('prompting/data_analysis_prompting.md', 'r') as f:
    template = f.read()

# 변수 대체
prompt = template.format(
    vpp_value=450,
    vdc_value=-200,
    phase=45,
    yttrium_peak=0.85,
    fo_ratio=1.2,
    rf_time=1200,
    energy=50000,
    recipe_name='Recipe_A',
    degradation_index=65
)

# AI 모델에 전달
response = ai_model.generate(prompt)
```

## 🎯 프롬프트 커스터마이징

각 프롬프트는 프로젝트의 특정 요구사항에 맞게 수정할 수 있습니다:

1. **도메인 지식 추가**: Dry Etch 공정의 특수성을 반영
2. **출력 형식 조정**: 필요한 정보만 포함하도록 수정
3. **임계값 조정**: 프로젝트 목표에 맞게 임계값 변경
4. **새로운 프롬프트 추가**: 특정 용도를 위한 새로운 프롬프트 작성

## ⚠️ 주의사항

1. **데이터 품질 확인**: 프롬프트 사용 전 입력 데이터의 정확성 확인
2. **컨텍스트 제공**: 충분한 배경 정보와 컨텍스트 포함
3. **단위 일관성**: 모든 수치의 단위를 명확히 표시
4. **신뢰 구간**: 예측값에는 반드시 신뢰 구간 포함
5. **검증**: AI 모델의 출력 결과는 항상 검증 필요

## 🔄 프롬프트 버전 관리

프롬프트를 수정할 때는:
- 변경 사항을 명확히 문서화
- 버전 번호 추가 (선택사항)
- 변경 이유 및 효과 기록
