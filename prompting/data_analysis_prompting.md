# 데이터 분석 프롬프트

## 목적
Dry Etch 공정 데이터를 분석하여 Y2O3 Focus Ring의 마모 패턴과 RUL 예측에 필요한 인사이트를 도출합니다.

---

## 프롬프트 템플릿

### 기본 데이터 분석 프롬프트

```
당신은 반도체 Dry Etch 공정의 설비 데이터 분석 전문가입니다.

다음 데이터를 분석하여 Y2O3 Focus Ring의 마모 상태를 평가하고 인사이트를 제공해주세요.

**입력 데이터:**
- RF 파라미터: Vpp={vpp_value}V, Vdc={vdc_value}V, Impedance Phase={phase}°
- OES 데이터: Yttrium Peak={yttrium_peak}, F/O Ratio={fo_ratio}
- 공정 부하: 누적 RF On-time={rf_time}시간, 누적 에너지={energy}J, Recipe={recipe_name}
- 현재 마모 진행도: {degradation_index}%

**분석 요청사항:**
1. 현재 마모 상태 평가 (정상 / 주의 / 위험)
2. 예상 잔존 수명 (RUL) 추정
3. 이상 징후 여부 확인 (Arcing 위험도 포함)
4. 교체 권장 시점 제안
5. 데이터 이상 여부 확인

**출력 형식:**
- 마모 상태: [정상/주의/위험]
- 예상 RUL: XX시간 (신뢰 구간: XX~XX시간)
- 이상 징후: [있음/없음] - [상세 설명]
- 교체 권장 시점: YYYY-MM-DD HH:MM
- 데이터 품질: [양호/주의/불량]
- 추가 권고사항: [권고사항]
```

---

### 시계열 데이터 분석 프롬프트

```
당신은 시계열 데이터 분석 전문가입니다.

Y2O3 Focus Ring의 마모 진행도를 추적하기 위해 다음 시계열 데이터를 분석해주세요.

**입력 데이터:**
- 시간 범위: {start_date} ~ {end_date}
- 데이터 포인트 수: {data_points}개
- 측정 간격: {interval}시간
- 주요 특성:
  - Vpp 시계열: {vpp_series}
  - OES Yttrium Peak 시계열: {yttrium_series}
  - 마모 진행도 시계열: {degradation_series}

**분석 요청사항:**
1. 마모 진행 추세 분석 (선형/지수/단계적)
2. 마모 가속화 구간 식별
3. 이상 구간 탐지 (급격한 변화, 노이즈)
4. 레시피별 마모 속도 비교
5. 예측 모델 적합성 평가

**출력 형식:**
- 마모 추세: [선형/지수/단계적] - 추세선 방정식
- 가속화 구간: [구간 1], [구간 2]
- 이상 구간: [구간 1] - [원인 분석]
- 레시피별 마모 속도: Recipe A={rate_a}%/시간, Recipe B={rate_b}%/시간
- 모델 적합성: [적합/부적합] - [이유]
```

---

### 챔버별 비교 분석 프롬프트

```
당신은 설비 엔지니어링 데이터 분석 전문가입니다.

여러 챔버의 Y2O3 Focus Ring 마모 데이터를 비교 분석하여 챔버별 특성을 파악해주세요.

**입력 데이터:**
- 분석 대상 챔버: {chamber_list}
- 각 챔버별 데이터:
  - Chamber {N}: 평균 Vpp={vpp}V, 평균 마모율={wear_rate}%/시간, 교체 주기={replacement_cycle}시간

**분석 요청사항:**
1. 챔버별 마모 속도 비교 및 편차 분석
2. 챔버별 특이사항 식별
3. 표준화 필요 여부 판단
4. 이상 챔버 식별 및 원인 추정
5. 최적 운영 방안 제안

**출력 형식:**
- 챔버별 마모 속도 순위: [순위]
- 편차 분석: 평균={mean}%/시간, 표준편차={std}%/시간
- 특이사항: [챔버명] - [특이사항]
- 표준화 필요: [예/아니오] - [이유]
- 이상 챔버: [챔버명] - [원인 추정]
- 최적 운영 방안: [방안 1], [방안 2]
```

---

### 레시피 영향도 분석 프롬프트

```
당신은 공정 레시피 분석 전문가입니다.

다양한 레시피가 Y2O3 Focus Ring 마모에 미치는 영향을 분석해주세요.

**입력 데이터:**
- 레시피 목록: {recipe_list}
- 각 레시피별 통계:
  - Recipe {name}: 사용 횟수={count}회, 평균 마모율={wear_rate}%/회, RF Power={rf_power}W

**분석 요청사항:**
1. 레시피별 마모 영향도 순위
2. RF Power와 마모율의 상관관계 분석
3. 고마모 레시피 식별 및 개선 방안
4. 레시피 가중치 계산 (누적 손상 모델용)
5. 레시피 최적화 제안

**출력 형식:**
- 레시피별 영향도 순위: [순위]
- RF Power 상관계수: {correlation}
- 고마모 레시피: [레시피명] - 마모율={rate}%/회
- 레시피 가중치: Recipe A={weight_a}, Recipe B={weight_b}
- 최적화 제안: [제안 1], [제안 2]
```

## 사용 예시

### 예시 1: 실시간 마모 상태 평가

```python
prompt = f"""
당신은 반도체 Dry Etch 공정의 설비 데이터 분석 전문가입니다.

다음 데이터를 분석하여 Y2O3 Focus Ring의 마모 상태를 평가하고 인사이트를 제공해주세요.

**입력 데이터:**
- RF 파라미터: Vpp=450V, Vdc=-200V, Impedance Phase=45°
- OES 데이터: Yttrium Peak=0.85, F/O Ratio=1.2
- 공정 부하: 누적 RF On-time=1200시간, 누적 에너지=50000J, Recipe=Recipe_A
- 현재 마모 진행도: 65%

**분석 요청사항:**
1. 현재 마모 상태 평가 (정상 / 주의 / 위험)
2. 예상 잔존 수명 (RUL) 추정
3. 이상 징후 여부 확인 (Arcing 위험도 포함)
4. 교체 권장 시점 제안
5. 데이터 이상 여부 확인
"""
```

### 예시 2: 이상 탐지

```python
prompt = f"""
다음 데이터에서 이상 징후를 탐지해주세요.

**입력 데이터:**
- Vpp 급증: 이전 평균=450V, 현재=520V (15% 증가)
- OES Yttrium Peak 감소: 이전=0.85, 현재=0.72
- 마모 진행도: 65% → 72% (1시간 내 7% 증가)

**분석 요청사항:**
1. 이상 징후 여부 판단
2. 가능한 원인 분석
3. 긴급 조치 필요 여부
4. 권장 조치 사항
"""
```

## 주의사항

1. **데이터 품질 확인**: 분석 전 데이터의 완전성과 정확성을 확인해야 합니다.
2. **컨텍스트 제공**: 레시피 정보, 챔버 정보 등 충분한 컨텍스트를 제공해야 합니다.
3. **단위 일관성**: 모든 수치의 단위를 명확히 표시해야 합니다.
4. **신뢰 구간**: 예측값에는 반드시 신뢰 구간을 포함해야 합니다.
